CHAPTER 1 / LEVEL 01

What is a signal?

A signal is a physical quantity that changes with time and carries information. Your voice shakes air — that shaking pattern is the signal. Voltage in a wire and brightness of light behave the same way: change over time, with a message inside.
सिग्नल भनेको समयसँग परिवर्तन हुने र सूचना बोक्ने भौतिक परिमाण हो। बोलेको आवाजले हावा हल्लाउँछ — त्यही pattern नै सिग्नल हो। तारको भोल्टेज वा बत्तीको उज्यालो पनि त्यस्तै हो।
WHY IT EXISTSInformation must travel. The signal is the vehicle. सूचना पुर्‍याउन सिग्नल चाहिन्छ।
FOUR EXAMPLESSound (air pressure) — Voltage (wire level) — Light (brightness) — Radio wave (shaped EM field).
RULE 01If nothing changes with time, it is not a signal. It is a value sitting still.
INFOTO SIGNALTRAVELRECEIVEINFO BACK

Every signal is a wiggle over time. A flat line is dead air.

Exam line: “What is a signal?” — Time-varying physical quantity carrying information. Add one example (voice, voltage).

CHAPTER 2 / LEVEL 02

Analog — the smooth one

Analog changes continuously. Any value inside the range is allowed — not just two steps. It is drawn as a smooth sine wave: natural voice, old radio, a volume knob, a dimmer.
अनालग लगातार परिवर्तन हुन्छ — range भित्र जुनसुकै मान। Smooth sine wave मा देखाइन्छ — प्राकृतिक आवाज, पुरानो रेडियो।
PEAKTop of the wave (+V). The highest point of the swing.
VALLEYBottom of the wave (−V). The lowest point.
AMPLITUDEHeight from the middle line. Taller means stronger / louder.
FREQUENCYCycles per second. Faster repetition means higher frequency.

Peak, valley, amplitude — all on one wave.

Common error: “Analog means old or broken.” It does not. Analog means continuous — a brand-new temperature sensor is still analog.
Exam line: draw a sine wave; label time axis, amplitude, peak, valley. Example: human voice.

CHAPTER 3 / LEVEL 03

Digital — the stepped one

Digital allows fixed levels only — usually two: HIGH = 1, LOW = 0. Its waveform is square steps, never smooth. This is the only language computers speak.
डिजिटलमा fixed मान मात्र — HIGH = 1, LOW = 0। Wave square-step हुन्छ। कम्प्युटरले यही बुझ्छ।
OFF — LOW / 0, 0V
Test rig: the switch

Operate it — lamp, voltage, binary value and waveform change together.

OFF = 0V = 0 / ON = 5V = 1

KNOB VS SWITCHAnalog is a dimmer (gradual). Digital is a wall switch (on or off).
WHY DIGITAL WONEasy to store, copy exactly, regenerate and error-check.
THE COSTIt needs ADC and DAC to talk to the smooth real world.
Exam line: draw a square wave; label HIGH/1, LOW/0, time. Example: computer data, MP3.

CHAPTER 4 / LEVEL 04

Binary — only 0 and 1

One binary digit is 1 bit. Eight bits make 1 byte. The golden exam rule: n bits give 2n combinations. 1 bit: 2. 2 bits: 4. 3 bits: 8. 4 bits: 16.
एउटा अंक = 1 bit। 8 bit = 1 byte। n bit, 2n वटा संयोजन।

Four-bit explorer — tap the bits

BIN 0000 / DEC 0 / 2^4 = 16 (0–15)

Weights left to right: 8, 4, 2, 1. So 0101 = 4+1 = 5; 1010 = 8+2 = 10. This exact conversion recurs in exams.

UnitSizeMemory hook
BIT0 / 1Smallest unit
NIBBLE4 bitsHalf a byte
BYTE8 bitsAbout one character
KB / MB / GB / TBeach step x10241024 B = 1 KB; 1024 MB = 1 GB
Memorise: 1 byte = 8 bits. 1 nibble = 4 bits. 3 bits = 8 patterns (000–111). 1010 = 10.

CHAPTER 5 / LEVEL 05

ADC and DAC — bridges both ways

SOUNDMICANALOGADCDATA TO PC
A microphone hears smooth sound. The ADC samples it — measuring the height thousands of times per second — and writes each measurement as numbers. Now the computer can store it. Sampling always loses a little. That is the price.
माइकले smooth आवाज सुन्छ। ADC ले छिनछिनमा नापेर (sampling) अंकमा लेख्छ।
DATADACANALOGSPEAKERSOUND
Playback reverses it. The DAC rebuilds a smooth voltage from the numbers; the speaker shakes air. You hear music.
बजाउँदा उल्टो — DAC ले अंकबाट smooth भोल्टेज बनाउँछ, स्पिकरले आवाज निकाल्छ।
Never forget: ADC = A to D = record IN. DAC = D to A = play OUT. रेकर्ड = ADC, बजाउने = DAC।
Common error: swapping the two. Alphabet helps — A comes before D, and recording starts in the Analog world.

CHAPTER 6 / LEVEL 06

Transmission — send it, survive noise

SOURCEENCODESENDCHANNELRECEIVEDECODE TO EAR
Phone, radio, TV, internet — one skeleton. Voice becomes a signal, rides a channel (wire, air, fibre), and is rebuilt at the far end. Noise is junk added on the way. Distortion is the shape bent. Digital wins because it can be regenerated and error-checked.
टेलिफोन, रेडियो, इन्टरनेट — खाका एउटै। Noise = बाटोमा थपिएको फोहोर, distortion = आकार बाङ्गिनु। Digital लाई regenerate + सच्याउन मिल्छ।
ANALOG CASESOld radio, live voice, rotary phone, temperature sensor.
DIGITAL CASESLaptop, phone call (ADC to packets to DAC), MP3, fibre network.
WHY DIGITAL WONProcess, store, send, copy exactly, fix. No generation loss like dubbing tapes.

Clean steps survive the trip. Smooth waves pick up dirt.
