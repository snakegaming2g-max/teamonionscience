FIG.06 — TWO SYMBOLS, INFINITE THINGS

Binary: only 0 and 1

One binary digit = 1 bit. 8 bits = 1 byte. Rule for the exam: n bits → 2ⁿ combos. 1 bit → 2 (0,1). 2 bits → 4 (00,01,10,11). 3 bits → 8. 4 bits → 16.
एउटा अंक = 1 bit। 8 bit = 1 byte। n bit → 2ⁿ वटा संयोजन। 1 bit → 2, 2 bit → 4, 3 bit → 8, 4 bit → 16।

Flip it yourself — 4-bit explorer

BIN 0000 · DEC 0 · 2⁴=16 (0–15)

Weights left→right: 8 · 4 · 2 · 1. So 0101 = 4+1 = 5, 1010 = 8+2 = 10.
